# Pi Provider

Pi is an opt-in integration through the independently installed `pi-acp` adapter.
Keep Pi behavior here and use the shared managed ACP execution backend.
Pi owns authentication, extensions, prompts and native session files.
ACP modes describe thinking levels, never permissions. Do not map them to Safe or Plan.
MCP configuration and delegated filesystem access are not supported by pi-acp 0.0.33.
Model discovery must preserve the user's shortlist and aliases.
